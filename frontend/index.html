Methodology & Calculation Specifications

1. Stop Loss Cluster Zone (P_stop)

Retail stops cluster tightly beneath recent key 24h swing support/resistance levels. The system identifies these levels dynamically:

$$P_{stop\_long} = \text{SwingLow}_{24h} \times (1 - 0.005)$$ $$P_{stop\_short} = \text{SwingHigh}_{24h} \times (1 + 0.005)$$

2. Cumulative Depth Trigger Cost (USDT)

The system computes the exact cumulative capital needed to exhaust all resting limit orders up to the cluster zone:

$$\text{Trigger Cost (USDT)} = \sum_{P_{bid} \ge P_{stop}} (P_{bid} \times Q_{bid})$$

3. Dual-Score Evaluation Model

• Probability Score (0-99): Derived from proximity to line, low trigger capital, and orderbook imbalance. • Impact Multiplier (0-99): Evaluates liquidity trap severity by comparing 24h turnover against the thin wall.
